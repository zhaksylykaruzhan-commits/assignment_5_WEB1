# Assignment 5 - JavaScript Basics (DOM Manipulation & Events)

Web Technologies Front-End Development, Astana IT University. Author: Zhaksylyk Aruzhan, group IT-2511.

Plain HTML, CSS and JavaScript. No libraries, no jQuery, no `onclick` attributes.

| Page | Files | What it is |
|------|-------|------------|
| `index.html` | `style.css` | Start page with links to the tasks |
| Task 1 | `task1.html`, `task1.js` | Higher or Lower game (3 lives, streak, best streak) |
| Task 2 | `task2.html`, `task2.js` | Kanban board built from an array (limit of 3 cards in progress) |
| Task 3 | `task3.html`, `task3.js` | Ticket builder form with live validation and live preview |

## Run locally

Open `index.html` in a browser, or run `python -m http.server` in this folder and open http://localhost:8000.
